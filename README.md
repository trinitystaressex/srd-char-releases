# SRD CHAR

A 3.5 SRD character sheet desktop app. Built as a fan project, free to use.

Not affiliated with or endorsed by Wizards of the Coast. Built around the freely-licensed SRD (System Reference Document) content only.

## Download

Grab the latest installer from the [Releases page](../../releases/latest). Download the `.exe`, run it, and follow the install wizard.

## ⚠️ Windows will probably warn you before it runs. Here's why, and what to do.

This app isn't code-signed. Code-signing certificates cost real money every year just to tell Windows "trust this," and since this is a free fan project, that cost isn't part of the plan right now. Unsigned software is completely normal for small indie and hobby projects, it just means Windows treats it as "unrecognized" the first time, not that anything is actually wrong with it.

You'll likely see one of these, sometimes both, the first time you run the installer and then again the first time you open the actual app:

**The usual case:**
A blue screen that says "Windows protected your PC." Click the small **More info** link, then click **Run anyway**. This only happens once per file, it won't ask again after that.

**If your PC is newer and has "Smart App Control" turned on** (mainly fresh Windows 11 installs):
You might see a message with no bypass option at all, just "Learn more" and "Get from app store." If that happens, you'll need to turn Smart App Control off from Windows Security → App & browser control before the app will run. That setting change is one-way (only reversible with a full Windows reinstall), so only do it if you're comfortable with that tradeoff. If you run into this and aren't sure, feel free to reach out and I'm happy to walk through it.

## Updating

Once you have the app installed, open it, go to Options → Settings, and turn on "Check for Updates on launch." It'll quietly check this repo's latest release each time you open the app and let you know right there if something newer's out, no need to come back to this page for future updates.

## Features

- Full 3.5 SRD character sheet: abilities, combat, saves, skills, feats, spells, items, weapons
- Multiple characters, each saved as its own file in `Documents\SRDCHAR`
- Auto-save, manual save, and safe-close handling, your character is never left half-saved
- A visual mannequin showing what you have equipped
- A conditions tracker for things like Prone, Stunned, Blinded
- Dice roller, spell prep tracking, and more
